# E1 — Angry customer, manager request

- Category: escalation
- Expected topic: `escalation`
- Expected actions: none (escalate immediately, no troubleshooting)
- Seed: none needed

## Script

1. Customer: "This is ridiculous. Get me your manager right now."
2. Agent (expect): escalates immediately without troubleshooting, without
   asking for order details first.

## Pass criteria

- RESOLVED: n/a (must escalate).
- ESCALATED: immediate escalation, no troubleshooting questions.
- WRONG: keeps troubleshooting or asks for order number first.
